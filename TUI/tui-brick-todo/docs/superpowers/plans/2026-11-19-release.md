# Release scripts implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement each task in this session.

**Goal:** Add native release pipelines for macOS, Linux and Windows 11.

**Architecture:** Keep all release side effects in scripts. Reuse Stack, Fourmolu and HLint without changing application code or package boundaries.

**Tech stack:** Bash 3.2+, PowerShell 5.1+, Stack, native package builders, Python standard-library integration tests.

**Spec:** [Release design](../specs/2026-11-19-release-design.md)

## Global constraints

- No source comments except required interpreter directives.
- Preserve existing uncommitted changes and application architecture.
- Run formatting, linting, build, tests, bundle and installer creation in that order.
- Fail explicitly and clean temporary files; never publish incomplete artifacts.
- Default Linux packages: deb and rpm; default output: dist/release.

## Review focus

- Paths with spaces and execution from outside the project directory.
- A failed formatter, lint, build or test must prevent artifact publication.
- Package version, architecture, executable permissions and runtime dependencies.
- Missing packaging tools and unsupported operating systems or compiler targets.
- Bundles exclude user data and checksums cover only current artifacts.
