# 실행 경고와 미사용 코드 정리

사용자 요청에 따라 `scripts/run.sh` 실행 경고를 재현하고 원인을 수정하며, 참조가 없는 코드를 제거한다. API 계약과 도메인 동작은 유지한다.

## 범위와 가정

- 기존 계층과 패키지 구성을 유지하고, 경고를 숨기는 옵션 대신 원인을 수정한다.
- 메모리 저장소는 테스트에서 사용하므로 서버가 SQLite를 사용한다는 이유만으로 제거하지 않는다.
- 미추적 `graft/` 디렉터리는 사용자 작업으로 간주해 보존한다.
- 시작 전 포트 3000이 비어 있음을 확인했다. 서버 시작 검증은 별도 포트와 임시 SQLite 데이터베이스를 사용한다.

## 역할 위임

- `warning_cleanup`: coder 역할. 검증 전용 스크립트로 재현하고, Haskell·Elm 소스와 패키지 설정에서 경고 원인과 미사용 코드를 정리한다.
- `orchestrator`: 영향 범위 확인, 작업 기록, 서버 시작 검증 및 독립 reviewer 검토 요청을 담당한다.

## 검증 계획

`scripts/run.sh --check-only`의 전체 출력과 HLint·GHC 경고를 확인하고, Haskell 및 Elm 테스트를 통과시킨다. 실제 서버 시작과 HTTP 정상 응답을 임시 데이터베이스로 확인한다. reviewer 승인 후 작업 보드를 완료 처리한다.
