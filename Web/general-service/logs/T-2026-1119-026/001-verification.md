# 개발 실행 스크립트 검증

Linux·macOS용 Bash와 Windows 11용 PowerShell에서 포맷, HLint 검사, Elm 포맷 검증, 빌드, 테스트, 서버 시작을 같은 순서로 실행한다. 검증 전용 옵션은 서버 시작을 생략한다.

- Linux 임시 작업본에서 검증 전용 실행이 통과했다. Haskell 테스트 24개와 Elm 테스트 18개가 통과했다.
- Linux 기본 실행에서 임시 SQLite 데이터베이스와 별도 포트를 사용해 Elm 진입 페이지의 HTTP 200 응답을 확인했다.
- Bash 문법 검사와 포맷 명령 실패 시 중단하는 동작을 확인했다.
- 스크립트 검토에서 확인한 Elm 테스트 의존성 설치 오류를 해결했다. npm에서 설치 가능한 `elm-test@0.19.3-0`으로 잠금 파일을 갱신했다.
- macOS 및 Windows 11에서의 실행은 확인하지 못했다.
