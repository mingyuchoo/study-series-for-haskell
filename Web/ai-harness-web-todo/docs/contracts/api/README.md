# API Contracts

HTTP API의 요청, 응답, 오류와 호환성 정책을 저장합니다.

## 새 계약에 포함할 내용

- 소유 패키지와 소비자
- 경로 또는 작업 이름과 버전
- 인증 및 인가 요구
- 요청과 응답 스키마
- 오류 모델과 재시도 가능 여부
- 멱등성 의미
- 시간 제한과 크기 제한
- 호환성 및 폐기 정책
- 연결된 계약 테스트

## 생성 문서와의 관계

라우트 목록은 손으로 관리하지 않습니다. `../../generated/route-map.md`가 Servant API 타입에서 생성되고, `../../generated/api-index.md`가 이 디렉터리의 계약 머리말에서 생성됩니다.

따라서 계약 문서의 머리말은 다음 형식을 지켜야 합니다.

```text
# API Contract: 이름
- 상태: Active
- 소유 패키지: api
- 소비자: 목록
- 버전: v1
```
