# Data Contracts

저장하는 데이터의 스키마, 의미, 보존과 분류 정책을 저장합니다.

## 새 계약에 포함할 내용

- 데이터 소유자와 허용된 소비자
- 필드의 의미, 타입과 제약
- 개인정보와 민감도 분류
- 보존, 삭제와 익명화 정책
- 마이그레이션과 하위 호환성
- 품질 검증과 스키마 테스트

## 생성 문서와의 관계

스키마 자체는 손으로 적지 않습니다. `src/store/schema/schema.sql`이 원본이고 `../../generated/db-schema.md`가 거기에서 생성됩니다. 이 디렉터리의 문서는 스키마가 설명하지 못하는 것, 곧 의미와 정책을 담습니다.
