# Definition of Done

코드가 동작하는 것만으로 작업은 완료되지 않습니다.

## Code

- 구현과 오류 처리가 완료되었습니다.
- `cabal build all --ghc-options=-Werror`가 경고 없이 통과합니다.
- `fourmolu --mode check`가 통과합니다. 형식 규칙은 저장소 루트의 `fourmolu.yaml`이 정합니다.
- 부분 함수를 사용하지 않았습니다. `head`, `fromJust`, 불완전한 패턴 매치가 없습니다.
- 실패를 예외가 아니라 `Either`로 표현했습니다. 예외는 복구 불가능한 상황에만 사용합니다.
- 불필요한 중복과 임시 디버깅 코드가 없습니다.
- 규칙을 어댑터에 복제하지 않고 `core`에 두었습니다.

## Verification

- 관련 단위 테스트가 통과합니다.
- 필요한 통합, 계약, 아키텍처, 보안, 회귀 테스트가 통과합니다.
- `scripts/quality/architecture-check.sh`가 통과합니다.
- 실패, 재시도와 경계 조건을 검증했습니다.
- 실행하지 못한 검증과 잔여 위험을 기록했습니다.

## Context

다음 중 변경된 항목이 있으면 대응하는 Canonical Source를 갱신했습니다.

- 아키텍처
- 도메인 불변조건
- API 또는 데이터 계약
- SQLite 스키마
- CLI 명령과 출력 형식
- 운영 동작과 환경 변수
- 보안 전제

생성 문서의 원본을 바꿨다면 해당 생성기를 실행했고 `scripts/context/validate-context.sh`가 통과합니다.

## Decision

새로운 장기적 아키텍처 결정을 만들었다면 ADR을 작성했습니다. 기존 결정을 대체했다면 상태와 연결 관계도 갱신했습니다.

## Learning

미래 작업에서도 반복해서 필요한 지식은 테스트, 정적 규칙, 계약, ADR, 도메인 문서 또는 에이전트 지침으로 승격했습니다.

일시적인 추측이나 작업 중간 사고는 저장하지 않습니다.
