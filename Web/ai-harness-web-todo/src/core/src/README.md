# core Source

순수 도메인 계층입니다. 이 디렉터리의 어떤 모듈도 `IO`를 수행하지 않습니다.

모듈별 책임은 `../README.md`의 표에, 계층 관계는 `../docs/architecture.md`에 있습니다.

## 배치 규칙

- 새 도메인 규칙은 기존 모듈 중 의미가 맞는 곳에 둡니다. 규칙마다 모듈을 만들지 않습니다.
- 값 객체를 추가하면 생성자는 `Todo.Core.Validation`에 둡니다.
- 저장이 필요한 새 연산은 `Todo.Core.Repository`의 포트에 추가하고 어댑터가 구현하게 합니다.
- 시각이 필요하면 인자로 받습니다. 여기서 시계를 읽지 않습니다.
