# store Failure Modes

| 실패 방식 | 탐지 | 안전한 동작 | 복구 |
|---|---|---|---|
| 동시 쓰기 경합 | `SQLITE_BUSY` 오류 | WAL 모드와 busy timeout으로 대기 | 시간 초과 시 호출자에게 오류 전달 |
| 파일 권한 부족 또는 경로 없음 | 연결 열기 실패 | 빈 데이터베이스를 만들지 않고 실패 | 경로와 권한 수정 |
| 손상되거나 알 수 없는 상태 문자열 | 디코딩 시 `statusFromName` 실패 | `StoreError`로 실패. 기본값 대체 금지 | 데이터 조사 후 수동 교정 |
| 형식이 깨진 시각 또는 날짜 문자열 | 디코딩 시 ISO 8601 파싱 실패 | `StoreError`로 실패 | 데이터 조사 후 수동 교정 |
| 코드보다 오래된 스키마 | `schema_version` 값 확인 | 열 추가는 재적용, 그 밖에는 진행하지 않음 | 마이그레이션 작성 (`TD-001`) |
| 태그 삽입 중 실패 | 트랜잭션 롤백 | 할 일 행만 남는 부분 상태를 만들지 않음 | 요청 재시도 |

실제 사고에서 확인한 실패 방식은 `../../../docs/incidents/INDEX.md`에 기록하고 회귀 테스트에 연결합니다.
