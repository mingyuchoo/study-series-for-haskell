# api Failure Modes

| 실패 방식 | 탐지 | 안전한 동작 | 복구 |
|---|---|---|---|
| 잘못된 JSON 본문 | Servant 본문 해석 | 400. 부분 처리하지 않음 | 클라이언트가 요청 수정 |
| 인식할 수 없는 상태나 우선순위 | `statusFromName`, `priorityFromName` | 400과 `invalid_request` | 클라이언트가 값 수정 |
| 존재하지 않는 식별자 | `UseCaseError` | 404와 `not_found` | 목록 재조회 |
| 허용되지 않은 상태 전이 | `TransitionError` | 409. 저장소 미변경 | 현재 상태 확인 후 재시도 |
| 저장 계층 잠금 경합 | 저장 계층의 busy timeout | 대기 후 진행, 실패 시 5xx | `../../../docs/incidents/INC-2026-001.md` 참고 |
| 손상된 저장 데이터 | `Todo.Store.Sqlite`의 `StoreError` | 기본값으로 위장하지 않고 5xx | 데이터 조사 |
| 예상하지 못한 예외 | WAI 기본 처리 | 내부 정보를 본문에 담지 않음 | 로그 확인 |

## 수신 주소

이 API는 인증이 없습니다. 실행 파일은 `127.0.0.1`에만 바인딩하며 수신 주소를 바꾸는 설정이 없습니다. 신뢰할 수 없는 네트워크에 노출하는 것은 현재 설계의 범위 밖입니다.

| 증상 | 원인 | 대응 |
|---|---|---|
| 다른 기기에서 연결이 거부됨 | 의도된 동작입니다 | 같은 기계에서 접속합니다. 원격 접속은 `../../../docs/product/vision.md`의 비목표입니다 |
| 포트가 이미 사용 중이어서 기동 실패 | 다른 프로세스나 이전 인스턴스 | `TODO_API_PORT`로 다른 포트를 지정합니다 |

과거 버전은 모든 인터페이스에 바인딩했습니다. 그 버전을 같은 네트워크에서 실행한 적이 있다면 인증 없는 쓰기 접근이 열려 있었습니다.
