# web Source

브라우저 어댑터 라이브러리입니다. 실행 파일 진입점은 `../app/Main.hs`이며 환경 변수를 읽어 warp을 루프백에 띄우는 일만 합니다.

모듈별 책임은 `../README.md`, 경계와 근거는 `../docs/architecture.md`에 있습니다.

## 배치 규칙

- HTML 생성은 `Todo.Web.View`에 모읍니다. 다른 모듈이 태그를 조립하지 않습니다.
- 렌더링은 순수 함수로 유지합니다. `IO` 안에서 HTML을 조립하면 출력을 테스트할 수 없습니다.
- 상태 전이와 조회 규칙을 여기서 다시 구현하지 않습니다. `Todo.Core`가 답을 주고 여기서는 표시만 합니다.
- 사용자 값에 `toHtmlRaw`를 쓰지 않습니다.
