# cli Source

명령줄 어댑터 라이브러리입니다. 실행 파일 진입점은 `../app/Main.hs`이며 파서를 실행해 이 라이브러리에 넘기는 일만 합니다.

모듈별 책임은 `../README.md`, 흐름과 종료 코드는 `../docs/architecture.md`에 있습니다.

## 배치 규칙

- 문법 정의는 `Todo.Cli.Options`, 출력 형식은 `Todo.Cli.Render`, 실행은 `Todo.Cli.Run`으로 나눕니다.
- 출력 생성은 순수 함수로 유지합니다. `IO` 안에서 문자열을 조립하면 형식을 테스트할 수 없습니다.
- 상태 전이와 조회 규칙을 여기서 다시 구현하지 않습니다.
