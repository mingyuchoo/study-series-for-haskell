# cli Tests

명령줄 문법과 출력 형식을 검증합니다. 검증 대상 목록은 `../docs/invariants.md`에 있습니다.

```bash
cabal test cli
```

## 규칙

- 파서는 `execParserPure`로 검증합니다. 실제 프로세스를 실행하지 않습니다.
- 출력은 순수 함수 `Todo.Cli.Render`를 직접 호출해 검증합니다.
- 명령 이름과 출력 형식은 사용자와 스크립트가 의존하는 표면입니다. 바꿀 때는 여기의 기대값을 함께 바꾸는 것이 계약 변경의 신호입니다.

실행 파일을 실제로 실행해 종료 코드까지 검증하는 테스트는 아직 없습니다. `../../../docs/tech-debt/active.md`의 `TD-002`로 추적합니다.
