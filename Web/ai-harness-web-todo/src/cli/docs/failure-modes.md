# cli Failure Modes

| 실패 방식 | 탐지 | 안전한 동작 | 복구 |
|---|---|---|---|
| 잘못된 명령줄 문법 | optparse-applicative | 사용법을 출력하고 2로 종료 | 사용자가 명령 수정 |
| 검증에 실패한 입력 | `Todo.Core.Validation` | 표준 오류로 사유 출력, 1로 종료. 저장소 미변경 | 사용자가 입력 수정 |
| 존재하지 않는 식별자 | `UseCaseError` | 어떤 식별자가 없는지 알리고 1로 종료 | `list`로 식별자 확인 |
| 허용되지 않은 상태 전이 | `TransitionError` | 현재 상태와 목표 상태를 모두 알림 | 사용자가 다른 전이 선택 |
| 데이터베이스 파일 접근 불가 | 연결 열기 실패 | 예외로 실패. 부분 결과를 출력하지 않음 | `--db` 경로와 권한 확인 |
| HTTP API와의 동시 쓰기 | 저장 계층의 잠금 처리 | WAL 모드로 대기 | `../../../docs/incidents/INC-2026-001.md` 참고 |
