# Integration Tests

저장 어댑터가 실제 매체 위에서 도메인 계약을 지키는지 검증합니다.

실행 위치: `../../src/store/tests`

## 다루는 것

- 임시 디렉터리의 실제 SQLite 파일을 대상으로 한 저장과 조회의 왕복
- 스키마 적용과 재적용의 안전성
- 태그 갱신과 삭제의 정리 동작
- 단위 테스트가 가짜 저장소로 검증한 계약을 실제 구현이 지키는지

가짜 저장소가 지키는 규칙을 실제 구현도 지킨다는 것을 여기서 확인합니다. 두 곳에서 같은 계약을 검증하는 것이 중복이 아니라 이 구조의 목적입니다.
