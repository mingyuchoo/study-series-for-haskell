# Contract Tests

생산자와 소비자가 `../../docs/contracts`의 공개 약속을 함께 지키는지 검증합니다.

실행 위치: `../../src/api/tests`

## 다루는 것

- `../../docs/contracts/api/TODO-API-v1.md`의 각 약속
- 응답 필드 집합, 성공 상태 코드, 오류 본문의 모양
- 오류 `code` 값과 HTTP 상태의 매핑
- 멱등성 규칙과 `dueOn`의 생략, `null`, 값 세 경우

## 실행 방식

실제 포트를 열지 않고 `Network.Wai.Test`로 애플리케이션에 직접 요청합니다. 포트 충돌과 대기 없이 결정적으로 실행하기 위한 선택입니다.

여기서 실패하는 변경은 소비자를 깨뜨리는 변경입니다. 테스트를 고쳐 통과시키기 전에 계약 문서와 버전 정책을 먼저 확인합니다.
